# machine — The Machine

Интерактивная генеративная работа: процедурная высотная модель рельефной панели проявляется штрихами плоттера. Фотография-референс не используется как подложка и не включена в опубликованную страницу.

## Локальный запуск

1. Откройте папку `machine` в GitHub Desktop или редакторе.
2. Для локального просмотра запустите сервер из этой папки:

   ```bash
   python -m http.server 8000
   ```

3. Откройте <http://localhost:8000>.

Не открывайте `index.html` двойным щелчком: браузеры часто блокируют JavaScript ES-модули на `file://`.

## GitHub Desktop

1. Распакуйте архив и выберите **File → Add Local Repository**.
2. Укажите папку `machine`.
3. Если GitHub Desktop сообщает, что это ещё не Git-репозиторий, выберите **Create a Repository** и укажите эту же папку.
4. Сделайте первый commit, например `Initial commit`.
5. Нажмите **Publish repository**.

## GitHub Pages

1. На GitHub откройте репозиторий → **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем **Save**.
4. После завершения публикации GitHub покажет адрес сайта в этом же разделе.

Все ресурсы подключаются относительными путями (`./style.css`, `./src/...`), поэтому проект работает и в корне GitHub Pages, и в репозитории с URL вида `username.github.io/repository/`.

## Структура

- `index.html` — интерфейс и canvas.
- `style.css` — оформление и адаптивная компоновка.
- `src/model.js` — процедурная высотная модель: рамки, круглая фаска, три углубления.
- `src/plotter.js` — построение двух слоёв, анимация, пауза/возобновление и звук Web Audio API.

## Рисование

- 66 горизонтальных синих линий, затем 66 вертикальных красных.
- Время одной линии по умолчанию — 2,4 секунды.
- Пауза между линиями — 0,42 секунды.
- Скорость и пауза регулируются ползунками.
- Звук создаётся браузером, без внешних аудиофайлов. Для воспроизведения требуется действие пользователя.

## О модели

Это процедурная реконструкция высотного поля по одному перспективному изображению, а не точный фотограмметрический скан или CAD-модель. Для улучшения совпадения можно корректировать параметры и функции в `src/model.js`.
